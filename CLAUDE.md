This is an application help learning and practicing Morse codes. The program shall be able to run on iphone and ipad. I want to make it in Swift and XCode and later I want to upload it to Appstore as a free application.

The functions shall the followingo:
1. Teach the morse code of characters. I want a list of english alphabet characters and the numbers. Once I select a char, the program will morse it on a typical morse tone. It also displays the morese code with dots and dashes. Like: L ..-.
2. Pratice receiving group of charachters: In an input form I can specify the set of characters and program will morse them in a random order using the typical morse tone. I want to be able to set the total number of characters in a pratice session I want to hear. I want to note the heard characters to paper and at the end of the session I want to compare the received and played charachters. In a later stage I want to have a camera based OCR to scan the paper based letters and compare it with the original output.
3. Giving any text file, the program shall be able to morse it.
4. I want a settings page where I can set the following parameters:
a. speed of morese code. in bps units
b. tone of the morse code. Frequency of the tone. And additional option would be to add nose or distortion to the tone simulating the HF radio quality

Please make sure the program doesn't collect any user data and it won't have any paywall feature so don't need to prepare for it.
